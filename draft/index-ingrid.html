root allOf Root fields id
Type: string

Die ID des Datensatzes. Die ID muss eindeutig im Index sein.
Examples:

"Für UMWELTNAVI <oid>-<part> i.e. 'nlwkn-dsk-4922-21000-0'"

"For InGrid Editor i.e. 'd43dad1f-a19f-4043-bca4-447cf5e7cabb'"

root allOf Root fields $schema
Type: string

Enthält die URL des JSON-Schemas, das für die Validierung verwendet wird.
Example:

"https://example.com/schemas/order/v2.1.0/schema.json"

root allOf Root fields schema_version
Type: string

Die Version des Schemas des Indexes.
Die Version richtet sich nach der Versionierung des InGrid Releases.
Semantic Versioning soll verwendet werden.
Zusätzlich kann eine Schema- Release-Nummer verwendet werden, z.B. 1.0.0-1
Examples:

"1.0.0"

"1.1.0-1"

"1.2.0-1"

root allOf Root fields metadata
Type: object

Enthält Metadaten über den Datensatz. Dies kann das Erstellungs- oder Änderungsdatum sein, oder aus welcher Quelle der Datensatz stammt.

root allOf Root fields metadata data_type
Type: string

Beschreibt den Typ des Metadatensatzes im Index. Jeder Eintrag beschreibt eine bestimmte Eigenschaft des Datensatzes. Die Eigenschaften z.B. im Portal verwendet, um eine bestimmte Darstellung des Metadatensatzes zu steuern. Der Wert muss vom Profil bestimmt werden.
Examples:

"UmweltNAVI Datensatz ['UMWELTNAVI']"

"InGrid Datensatz ['INGRID']"

"UVP Datensatz ['UVP']"
